# P1erce

个人代码仓库。

## 关于

这里用于存放个人项目、实验代码和日常脚本。仓库由 WorkBuddy 初始化，提交身份已配置为 GitHub noreply 邮箱，因此所有提交会自动归属到 [@zscvgnmk111-rgb](https://github.com/zscvgnmk111-rgb)。

## 环境

本地开发环境已就绪：

| 组件 | 版本 |
| --- | --- |
| Git | 2.55.0 |
| Python | 3.13.12 / 3.12.10 |
| Node.js | 22.22.2 / 24.15.0 |

## 克隆

```bash
git clone git@github.com:zscvgnmk111-rgb/P1erce.git
```

> 注意：本机网络环境下 `github.com` 的 HTTPS 通路不可用（代理返回 502），请使用 SSH 地址克隆和推送。
